# Phase 6 Plan 1: mdBook Scaffolding & Scripting Reference Pages

## Objective

Create the Cereka documentation site using mdBook — build the scaffolding (directory structure, book config), write all 10 scripting reference pages with accurate content based on the engine's actual feature set, and create the user guide and example pages referenced in the existing SUMMARY.md.

## Context

The docs/ directory already exists with:
- `docs/book.toml` — mdBook configuration (title, theme, search, print)
