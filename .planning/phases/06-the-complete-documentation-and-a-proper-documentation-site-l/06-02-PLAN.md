    ### docs/src/variables-and-expressions.md — Variables Deep-Dive
    Structure:

    1. **Overview** — two types: string variables (set) and numeric variables ($)
       - Variables persist for the entire game session across scenes and scripts
       - Variables are global (not scoped to labels or scripts)
       - Stored in save data (cereka_save_data.hpp: variables + numVariables maps)

    2. **String Variables (`set`)** — from CLAUDE.md lines 98-99:
       - `set <name> <value>` — creates or overwrites a string variable
       - Values don't need quotes unless they contain spaces
       - Used with if/else for branching narrative

    3. **Numeric Variables (`$`)** — from CLAUDE.md lines 101-109:
       - `$ <name> = <expression>` — assign expression result
       - `$ <name> += <expression>` — add
       - `$ <name> -= <expression>` — subtract
       - `$ <name> *= <expression>` — multiply
       - `$ <name> /= <expression>` — divide
       - Expression support: numbers, variable names, `+ - * /` operators
       - * / has precedence over + - (e.g., `$ damage = base + bonus * 2` → bonus*2 then + base)

    4. **Variable Substitution in Dialogue (`{var}`)** — from CLAUDE.md line 78:
       - `{varname}` inside narrate or say strings is replaced with current value
       - Works for both string and numeric variables
       - Examples: `narrate "gold={gold}, hp={hp}"`

    5. **Complete Example** — extended script showing:
       - Setting player name with set
       - Building stats with $ arithmetic
       - Using {var} in dialogue
       - Using numeric comparisons in if conditions
