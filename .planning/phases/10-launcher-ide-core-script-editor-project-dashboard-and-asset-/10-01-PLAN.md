# Plan 10-01: Launcher IDE Core — Infrastructure + Project Metadata

## Objective

Set up the build system for the IDE panels, add project metadata persistence, and prepare the launcher navigation for new pages. Also establish the tree-sitter-cereka LSP server as a build-time dependency.

---

**Files:** launcher/CMakeLists.txt

### Task 2: Project metadata system

**Files:** launcher/project_metadata.hpp (new), launcher/project_metadata.cpp (new)
**Action:**

### Task 4: LSP server bootstrap

**Action:** 
- Tree-sitter-cereka repo lives at sibling level: `~/personal/dev/tree-sitter-cereka/`
- LSP server lives at: `tree-sitter-cereka/lsp/server.js`
- Standalone binary built via Node.js SEA (Single Executable Application) using the standard postject workflow:
  ```bash
  cd tree-sitter-cereka/lsp
  # 1. Generate the SEA config blob
  node --experimental-sea-config -c sea-config.json
  
  # 2. Copy the Node.js binary
  cp $(which node) dist/cereka-lsp
  
  # 3. Inject the SEA blob (requires npx postject)
  npx postject dist/cereka-lsp NODE_SEA_BLOB dist/cereka-lsp.blob \
    --sentinel-fuse NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2
  
  # 4. macOS: codesign the result
  [ "$(uname)" = "Darwin" ] && codesign --sign - dist/cereka-lsp
  ```
- Where `sea-config.json` is:
  ```json
  { "main": "server.js", "output": "dist/cereka-lsp.blob", "resources": ["../tree-sitter-cereka.wasm"] }
  ```
- Binary output: `tree-sitter-cereka/lsp/dist/cereka-lsp`
- Launcher resolves path: first check `dev/tree-sitter-cereka/lsp/dist/cereka-lsp`, fall back to `../../tree-sitter-cereka/lsp/dist/cereka-lsp` relative to launcher binary
- If binary not found: launcher starts normally, editor features are unavailable (graceful degradation)
- Document build steps in CLAUDE.md
