# Plan 10-04: Project Dashboard + Asset Browser

## Objective

Build the enhanced project dashboard (metadata, templates, quick run) and the complete asset browser (tree, thumbnails, audio, drag-drop, missing asset warnings).

---

## Tasks

### Task 1: Enhanced project dashboard

**Files:** launcher/dashboard_page.hpp, launcher/dashboard_page.cpp, launcher/project_manager.cpp
**Action:**
- Replace the existing project detail page with richer dashboard:
  - Project title (editable)
  - Metadata display: UUID, last opened, total play time, engine version (from .cereka/project.json)
  - Quick run button → launches `CerekaGame --headless --entry <current_entry>`, output to log panel
  - Quick spec-run: dropdown of all .spec.crka files → launches `CerekaGame --script <file>`, output to log panel, shows PASS/FAIL summary
  - "Open in Editor" button → switches to EditorPage and opens main.crka
- Update ProjectManager to track play time (start timer on launch, save on exit)
- **Crash safety**: periodic metadata save every 60 seconds via QTimer, not only on clean exit

### Task 2: Template gallery

**Files:** launcher/template_model.hpp, launcher/template_model.cpp, launcher/dashboard_page.cpp
**Action:**
- Template gallery section on dashboard showing available project templates
- Templates: "Blank Project" (minimal), "Default" (current templates.hpp scaffold)
- Template preview: name + short description
- Click → create new project from template
- Templates defined as data (not hardcoded UI)

### Task 3: Asset browser tree

**Files:** launcher/asset_browser_page.hpp, launcher/asset_browser_page.cpp
**Action:**
- Tree view of assets/ subdirectories (bg, characters, sounds, fonts, ui)
- Rooted at the project's assets/ directory
- QFileSystemWatcher for auto-refresh on file changes
- Icons: folder icons for directories, file type icons for .png/.jpg/.ogg/.wav/.ttf/.otf
- Click file → show preview in right panel

### Task 4: Asset preview panel

**Files:** launcher/asset_browser_page.cpp
**Action:**
- Image files (.png, .jpg): thumbnail rendered via QPixmap, scaled to fit panel, preserve aspect ratio
- Audio files (.ogg, .wav): play/stop button + waveform placeholder. Uses QMediaPlayer via Qt6::Multimedia
- Font files (.ttf, .otf): show font preview text ("The quick brown fox...")
- No preview for other file types (show "No preview available")

### Task 5: Drag-drop

**Files:** launcher/asset_browser_page.cpp, launcher/asset_browser_page.hpp
**Action:**
- Drag from asset tree → QDrag with MIME data containing file path
- Editor accepts drops → inserts path at cursor position (CodeEditor drop handler from 10-02-04)
- Missing asset warnings deferred to Phase 11 (requires LSP server extension — not feasible under D-07 constraints)
