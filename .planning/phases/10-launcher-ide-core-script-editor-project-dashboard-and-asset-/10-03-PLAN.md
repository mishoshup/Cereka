# Plan 10-03: Editor UX Features — Tabs, Split, Find Panel, Outline

## Objective

Build the complete editor UX on top of CodeEditor from 10-02: tabbed multi-file editing, split-pane, full-featured find/replace panel, and document outline.

---

## Tasks

### Task 1: Tab bar

**Files:** launcher/editor_tab_bar.hpp, launcher/editor_tab_bar.cpp
**Action:**
- Custom tab bar widget integrating with EditorPage
- Each tab represents an open .crka file
- Click to switch, middle-click to close, drag to reorder (QTabBar supports this natively)
- Unsaved file indicator (dot or asterisk on tab)
- Right-click context menu: Close, Close Others, Close All, Copy Path
- Tab bar at top of editor area (above the CodeEditor widget)

### Task 2: Split-pane

**Files:** launcher/editor_page.hpp, launcher/editor_page.cpp
**Action:**
- QSplitter-based horizontal split
- Button in tab bar or toolbar: "Split Right" (Ctrl+\) 
- Split supports:
  - Two different files (pick from file tree for second pane)
  - Same file in both panes (scroll independently, useful for long files)
- **LSP model**: One LspClient connection shared across all panes. Each document has a unique URI. For same-file split, use unique URIs with pane suffix (e.g., `file:///main.crka#pane=left` and `file:///main.crka#pane=right`). LSP server treats them as separate documents. Version numbers are per-URI, no conflict.
- **Critical: only the active pane (receiving keyboard input) sends `didChange`**. The inactive pane opens the document as read-only with `didOpen` but never sends `didChange` — its document is a static snapshot until the user focuses it. This prevents duplicate/conflicting `didChange` notifications from the shared QTextDocument. Focus tracking: CodeEditor::focusInEvent marks the pane as active; EditorPage ensures only the active pane's editor is connected for change notifications.
- Merge button to unsplit
- Drag tab from tab bar to split (like VS Code — requires QTabBar mouse event handling to detect drag start, create new pane with same document)

### Task 3: Find/Replace panel

**Files:** launcher/find_panel.hpp, launcher/find_panel.cpp
**Action:**
- Dockable panel at bottom of editor (LazyVim/VS Code style)
- Search input: search as you type, highlight all matches in editor via QTextEdit::ExtraSelections
- Results list: show each match with line number + context text, click to navigate
- Replace input: replace one (Ctrl+H) or replace all
- Options: case-sensitive toggle, whole-word toggle, regex toggle
- Navigation: Enter/Shift+Enter to go next/previous match, F3/Shift+F3
- Close: ESC
- QShortcut: Ctrl+F to open find, Ctrl+H to open find+replace

### Task 4: Document outline panel

**Files:** launcher/outline_panel.hpp, launcher/outline_panel.cpp
**Action:**
- Side panel listing all `label` definitions in current file
- Uses LSP `textDocument/documentSymbol` response
- Click label → navigate to that line in editor
- Hierarchical if labels are structured (by prefix or indentation)
- Auto-refresh on file change
