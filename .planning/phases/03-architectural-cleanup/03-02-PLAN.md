    IRenderContext pure virtual interface:
    ```cpp
    class IRenderContext {
    public:
        virtual ~IRenderContext() = default;

        // Lifecycle
        virtual void Clear(Color c) = 0;
        virtual void Present() = 0;

        // Drawing
        virtual void FillRect(Rect rect, Color c) = 0;
        virtual void FillScreen(Color c) = 0;
        virtual void DrawTexture(ITexture &tex,
                                 const Rect *srcRect,
                                 const Rect *dstRect) = 0;

        // Texture management — returns nullptr on failure
        virtual std::unique_ptr<ITexture> CreateTexture(const std::string &filepath) = 0;

        // Text textures — take TTF_Font* as param (font stays SDL type)
        virtual std::unique_ptr<ITexture> CreateTextTexture(
            TTF_Font *font, const std::string &text, Color color) = 0;
        virtual std::unique_ptr<ITexture> CreateTextTextureWrapped(
            TTF_Font *font, const std::string &text, Color color, int wrapWidth) = 0;

        // Blend mode
        virtual void SetBlendMode(bool enabled) = 0;

        // Dimensions
        virtual int Width() const = 0;
        virtual int Height() const = 0;

        // Access to raw SDL_Renderer* for existing code that needs it during migration
        // REMOVED after full migration — do not add new uses
        [[deprecated("Use IRenderContext methods instead of accessing SDL_Renderer* directly")]]
        virtual SDL_Renderer *NativeRenderer() = 0;
    };
    ```
    Note: `NativeRenderer()` is a temporary escape hatch so that existing draw code in cereka_draw.cpp and state draw methods continues to compile during migration. Plan 03-03 (UIManager) removes all direct SDL_Renderer* access. See D-04 for full interface contract.

    **`src/renderer/sdl_render_context.hpp`**:
    ```cpp
    #include "irender_context.hpp"
    #include <SDL3/SDL.h>

    namespace cereka {
    class SdlRenderContext : public IRenderContext {
    public:
        SdlRenderContext(SDL_Renderer *renderer, int width, int height);
        // ... all virtual overrides ...
    private:
        SDL_Renderer *m_renderer;
        int m_width, m_height;
    };
    }
    ```

    **`src/renderer/sdl_render_context.cpp`**:
    Implement all IRenderContext methods delegating to SDL3:
    - `Clear`: `SDL_SetRenderDrawColor` + `SDL_RenderClear`
    - `Present`: `SDL_RenderPresent`
    - `FillRect`: `SDL_SetRenderDrawColor` + `SDL_RenderFillRect`
    - `FillScreen`: `SDL_SetRenderDrawBlendMode` + `SDL_SetRenderDrawColor` + `SDL_RenderFillRect` with nullptr
    - `DrawTexture`: `SDL_RenderTexture` with optional src/dst rects
    - `CreateTexture`: `IMG_LoadTexture(m_renderer, ...)` — wrap in SdlTexture (inner class implementing ITexture)
    - `CreateTextTexture`: Calls `text_renderer::RenderText` (but needs to return ITexture*) — see Task 2
    - `CreateTextTextureWrapped`: Same but wrapped variant
    - `SetBlendMode`: `SDL_SetRenderDrawBlendMode(m_renderer, enabled ? SDL_BLENDMODE_BLEND : SDL_BLENDMODE_NONE)`
    - `Width`/`Height`: return stored dimensions
    - `NativeRenderer`: return `m_renderer`

    Create a private inner class `SdlTexture : public ITexture` that holds `SDL_Texture*` and implements `Width()`/`Height()` via `SDL_GetTextureSize`.

    Include `<SDL3_image/SDL_image.h>` for `IMG_LoadTexture`.
