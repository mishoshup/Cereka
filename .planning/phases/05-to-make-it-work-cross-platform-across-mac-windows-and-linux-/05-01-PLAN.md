## Objective

Fix two macOS-specific display bugs:
1. Resolution distortion — game renders incorrectly inside the window despite correct window frame
2. Font not displayed — dialogue text box is empty on macOS

## Scope

### In Scope
- Add `SDL_SetRenderLogicalPresentation()` call after renderer creation to fix coordinate space mismatch on Retina/HiDPI displays
- Investigate and fix font rendering failure on macOS (text invisible in dialogue box)
- Headless unit tests that verify both fixes without a display

### Out of Scope
- Linux/Windows display issues (confirmed working)
- Font styling, markup, or text layout changes
- Non-text UI elements (buttons, backgrounds — only text box)
