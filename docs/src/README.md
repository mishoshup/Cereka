# Cereka Documentation

Welcome to the Cereka game engine documentation.

Cereka is a visual novel engine where game authors write only `.crka` scripts — no C++ needed.

- [Project Structure](project-structure.md) — how game projects are organized
- [Build & Package](build-and-package.md) — distribute your game

## Features

- **Script-driven** — write visual novels in the `.crka` scripting language
- **Scene management** — backgrounds, character sprites, positioning
- **Dialogue system** — character speech, narration, text markup
- **Audio** — looping BGM, one-shot SFX, crossfade transitions
- **Menu & choices** — branching narratives with player decisions
- **Variable system** — string and numeric variables with arithmetic
- **Conditionals** — `if/else/endif` with full comparison operators
- **Flow control** — labels, jumps, includes, call subroutines
- **Save/Load** — 10-slot save system with JSON persistence
- **UI theming** — customizable textbox, name box, buttons, fonts
- **Scene graph** — advanced node-based scene manipulation
- **Cross-platform** — Linux and Windows native support
